# スクリーンショット置き場

ここに画像を置いて、リポジトリ直下の README.md から参照します。

推奨する4枚（ファイル名はこのとおりにすると README をそのまま使えます）

| ファイル名 | 内容 | 撮り方 |
|---|---|---|
| `overview.png` | アプリ全体の画面（CSVと走行動画を読み込んだ状態） | ブラウザで全画面にして Windows の Win + Shift + S で範囲を選んでコピー → ペイントに貼って保存 |
| `hud.png` | HUD部分の拡大（速度・サーボ角度・センサが見える状態） | 同上。左の1列だけを範囲選択 |
| `lock.png` | 電磁ロック表示（デューティが黄色＋斜線のコマ） | コマ送りでロックの瞬間を出してから撮影 |
| `export.png` | 書き出し設定のサイドバー | 同上 |

1枚あたり 2MB 以下を目安にしてください。
